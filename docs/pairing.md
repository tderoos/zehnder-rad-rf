# Pairing handshake

From the manual (verkorte handleiding RF-bediening):

1. Radiator on mains: LED steady purple = not paired.
2. Press LED 2x short: LED blinks purple, radiator in pairing mode for 1 minute.
3. On remote: press `mode` (display shows `RF 0`), then hold `+` for 5 s.
4. On success display shows `RF 1`; press `mode`. Remote drops to frost protection mode.

Reset: hold LED ~10 s until fast purple blinking; remote reset via advanced
menu `9 So`, press `+` twice until `8888`.

Capture the RF exchange during step 3-4 to learn how the remote ID / network
ID is registered.
